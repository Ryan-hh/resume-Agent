# 简历助手・智能小昊

一个纯前端的智能简历制作工具：**表单 / 对话输入 → A4 实时预览 → AI 智能体改写 → 一键导出 PDF**。

内置 AI 助手「**智能小昊**」：你用自然语言描述需求，它直接调用工具把修改写进简历并实时渲染。所有数据只保存在浏览器本地（localStorage），无需注册、无需服务器，任意静态托管即可运行。

> 产品介绍页：
>
> `/#/home`
>
>  ｜ 主应用：
>
> `/`
>
> （简历列表）→ 
>
> `/workbench/:id`
>
> （编辑工作台）

## 功能总览



| 能力       | 说明                                                                      |
| -------- | ----------------------------------------------------------------------- |
| AI 对话式编辑 | 右侧对话即可改简历：「把这段经历润色一下」「主题换成蓝色」「删掉第二段实习」，智能小昊直接落地修改                       |
| A4 实时预览  | 三栏工作台，编辑即所见即所得；长文本按 Word 式**行级分页**自动断页，纸张比例、页边距与导出一致                    |

| 撤销 / 重做  | 所有修改进历史栈（每份简历最多 50 步），AI 改错可逐步回退                                        |
| 拖拽排序     | 板块与条目自由拖拽排序、显示 / 隐藏，按招聘方关注点重组结构                                         |

| 智能导入     | PDF / Word (DOCX) / TXT / MD / 图片 / JSON 自动识别并填入对应板块                    |

| 本地隐私     | 数据只存浏览器 localStorage，可选本地文件夹自动备份，不上传服务器                                 |
| 深浅色主题    | 跟随系统或手动切换                                                               |

## 快速开始



```
\# 1. 安装依赖（项目存在历史 peer 冲突，必须加 --legacy-peer-deps）

npm install --legacy-peer-deps

\# 2. 启动开发服务器

npm run dev          # → http://localhost:5173

\# 3. 生产构建（产物在 dist/）

npm run build        # 内部先执行 tsc -b 类型检查再打包

\# 4. 本地预览生产构建

npm run preview
```

**部署**：`npm run build` 后把 `dist/` 目录放到任意静态托管（Vercel / GitHub Pages / Nginx / 对象存储）即可。应用是 HashRouter，无需服务端路由配置。

## 使用指南

### 1. 首次打开



* 打开应用（`/#/`）会自动创建一份**示例简历**（张伟的完整示例数据），直接进入编辑。

* 若首次启动时已有旧版本数据，store 会自动执行**数据迁移**（版本号升级、结构修补），无需手动处理。

* 所有功能无需注册登录。

### 2. 简历列表页（`/#/`）



| 操作   | 做法                                                             |
| ---- | -------------------------------------------------------------- |
| 新建简历 | 点击「新建简历」，选择模板，可创建空白简历或示例简历                                     |
| 打开简历 | 点击简历卡片进入工作台（`/workbench/:id`）                                  |
| 复制简历 | 卡片上「复制」按钮，生成「xxx - 副本」（自动编号去重）                                 |
| 删除简历 | 卡片上「删除」，二次确认后移除（内存与备份文件同步清理）                                   |
| 导入简历 | 右上「导入」，支持 PDF / DOCX / TXT / MD / 图片 / JSON（详见[导入简历](#9-导入简历)） |
| 切换简历 | 多份简历互不干扰，投不同岗位分开维护                                             |

### 3. 编辑工作台（三栏布局）

工作台是 VS Code 风格三栏：



```
┌─────────────┬──────────────┬─────────────┐

│  左侧        │   中间        │   右侧       │

│  编辑表单     │  A4 实时预览   │  AI 智能小昊  │

└─────────────┴──────────────┴─────────────┘
```



* **面板宽度可拖拽**：拖动面板交界处调整比例，双击交界处恢复默认，键盘方向键微调（聚焦分隔条后按 ← / →）。

* **底部控制条**：可单独显示 / 隐藏左侧、预览、AI 面板；窄窗口（< 1200px）默认收起 AI 面板。

* 编辑左侧任意字段，中间预览**即时刷新**；AI 面板按需懒加载，不影响首屏。

### 4. 左侧：编辑各板块

左侧顶部是板块选项卡，每个板块一个编辑页：



| 板块    | 编辑内容                                 |
| ----- | ------------------------------------ |
| 基本信息  | 姓名、求职意向、联系方式、出生年月、头像（可上传 / 移除）、自定义字段 |
| 教育背景  | 学校、专业、学历、起止时间（支持「至今」）、在校经历条目         |
| 专业技能  | 富文本（技能点列表）                           |
| 工作经历  | 公司、职位、起止时间、工作内容（富文本），条目可增删、拖拽排序      |
| 实习经历  | 同工作经历                                |
| 项目经历  | 项目名、角色、时间、描述（富文本），可拖拽排序              |
| 荣誉证书  | 富文本                                  |
| 自我评价  | 富文本                                  |
| 自定义板块 | 新增自定义板块（可改名、显隐），内容为富文本               |



* **条目排序**：教育 / 工作 / 实习 / 项目条目支持拖拽调整顺序。

* **时间范围**：开始时间、结束时间分开填，勾选「至今」后结束时间自动留空。

* **板块显隐与顺序**：工作台底部或左侧可重排板块顺序、开关显示隐藏（影响预览与导出）。

### 5. 富文本编辑

所有「富文本」输入框使用 Tiptap 所见即所得编辑器，工具栏按钮：



| 按钮        | 功能                     |
| --------- | ---------------------- |
| **B**（加粗） | 选中文字后点击，加粗 / 取消加粗      |
| 无序列表      | 把当前段落切换为圆点列表；列表内回车新增条目 |
| 有序列表      | 把当前段落切换为数字列表；跨页时序号自动连续 |
| AI 润色     | 把当前内容交给智能小昊润色，确认后应用    |



* **缩进**：光标在段落 / 列表项内按 `Tab` 增加缩进（段落为首行缩进，列表项整体右移），`Shift+Tab` 减少缩进。

* **退出列表**：在列表末尾空项再按一次回车，即退出列表回到普通段落。

* 列表末尾不会残留删不掉的空行；跨页时列表条目按 Word 方式续排，序号 / 圆点不重复。

### 6. 模板与样式



* **切换模板**：工作台内选择模板（7 套），切换只换布局与标题样式，**内容不丢失**。

* **全局设置**（左侧设置面板）：


  * 主题色（影响标题、线条、强调元素）

  * 基础字号 / 标题字号 / 副标题字号

  * 板块间距 / 段落间距 / 页面内边距

  * 页头对齐（左 / 中 / 右）

  * 年龄显示开关、图标模式开关

* 所有样式修改实时反映在预览中。

### 7. 中间：A4 实时预览



* 预览区按真实 A4 纸张比例（794 × 1123）逐页渲染，每页独立白纸。

* **行级分页**：任何富文本（纯文本 / 列表 / 混合）超出一页时，像 Word 一样在页底按行截断，剩余内容流到下一页，不会整块跳页。

* **跨页规则**：条目（教育 / 工作 / 项目等）可在页间断开；上一页末尾已显示的**标题行不会在下一页重复**；有序列表跨页序号连续。

* 预览区域支持缩放（面板宽度变化自动等比缩放），不出现横向滚动。

### 8. 右侧：AI 智能小昊

**使用前需先在设置页配置模型**（见[设置页](#11-设置页ai-模型配置--备份)），否则对话不可用。



* 在右侧对话框用自然语言下达指令，例如：


  * 「把项目经历里的第二段润色一下」

  * 「帮我加粗自我评价里的第一句话」

  * 「把工作经历里的 xx 公司删掉」

  * 「主题换成蓝色，板块间距大一点」

* 智能小昊会展示**思考过程**与**工具调用卡**（调用哪个工具、写入什么参数均可查看），修改完成后**询问你是否应用**，确认后才落地。

* **AI 改错怎么办**：每次修改都进历史栈，可点「撤销」逐步回退，或点「撤销本次全部改动」快照一次恢复。

* 编辑器内点击「AI 润色」会把当前板块内容发给小昊润色，同样确认后应用。

### 9. 导入简历

入口在简历列表页右上「导入」，支持：



| 格式               | 处理方式                                         |
| ---------------- | -------------------------------------------- |
| PDF              | 优先抽取文本层（快）；扫描件 / 无文本层自动转图片走视觉模型              |
| 图片（PNG/JPG/WebP） | 压缩后走视觉模型识别                                   |
| Word（.docx）      | Mammoth 解析为文本后走 AI 填表；`.doc` 旧格式请另存为 `.docx` |
| TXT / MD         | 直接作为文本走 AI 识别                                |
| JSON             | 本系统导出的 `.json` 简历文件，结构化导入，数据完整保留             |

> PDF / 图片 / DOCX / TXT / MD 均依赖 AI 模型识别，需已配置模型；JSON 导入不依赖 AI。

### 10. 导出简历

工作台预览区下方「导出」按钮，三种格式：



| 格式         | 说明                          |
| ---------- | --------------------------- |
| **PDF**    | 按 A4 纸张分页导出，排版与预览一致，文字清晰    |
| **长图 PNG** | 导出为一张完整的长图片（连续内容，无分页间距）     |
| **JSON**   | 导出结构化数据文件，可在其他设备导入继续编辑 / 备份 |

所有导出在本地完成，数据不离开浏览器。

### 11. 设置页（AI 模型配置 / 备份）



* **AI 配置**（`/#/ai`）：


  * 选择 Provider：OpenAI / Anthropic Claude / Google Gemini / 自定义（OpenAI 兼容接口，填 baseUrl）

  * 填入 API Key、模型名，可「测试连接」验证

  * 密钥只保存在本机浏览器，不共享、不上传

* **备份**：设置页开启「本地文件夹备份」后（需授权目录），每次编辑防抖 1.5s 自动把简历 JSON 写入本地文件夹，删除简历时同步清理文件。用于数据兜底。

### 12. 快捷键一览



| 按键                                    | 功能                   |
| ------------------------------------- | -------------------- |
| `Tab` / `Shift+Tab`                   | 富文本内增加 / 减少缩进        |
| `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） | 撤销 / 重做（Tiptap 编辑器内） |
| 面板分隔条聚焦后 `←` / `→`                    | 调整面板宽度，`双击` 重置       |
| 页面右上                                  | 深浅色主题切换              |

## 数据与存储



* **存储位置**：浏览器 `localStorage`，key 为 `resume-assistant-storage`，Zustand persist 自动写入。

* **存储内容**：所有简历数据（`resumes`）、当前激活简历 ID、首次运行标记。撤销历史不持久化。

* **数据迁移**：store 带版本号（当前 v8），启动时自动执行结构迁移（日期字段拆分、自定义板块迁移、模板序号化等），损坏数据自动修补。

* **模板存储**：简历存的是模板**序号**（`"0"`\~`"6"`），模板列表增删时自动回退到默认模板，简历不会打不开。

* **本地文件备份**（可选）：授权文件夹后自动写入 `resume-<id>.json`。

## 设计与实现要点



* **无后端**：存储、导入解析、导出全部由浏览器原生能力完成，静态托管即可运行。

* **数据驱动渲染**：简历是结构化 JSON，模板是纯渲染函数；智能小昊通过工具读写同一份数据，任何修改实时反映在 A4 预览上。

* **行级 A4 分页**：预览不依赖浏览器原生分页，而是「测量树（真实 A4 布局）→ 块收集 → 行级截断测量（二分 + Range 定位字符偏移）→ 按页克隆 DOM」。纯文本、列表、混合块统一按视觉行断页，跨页隐藏重复标题、列表序号连续。

* **富文本尾随空行治理**：列表末尾 Fitter 自动补的空段落通过纯 CSS（`:has()` 高度压零 + 预览 `display:none`）处理；失焦时清理文档末尾空块，保证「删不掉的空行」彻底消失。

* **字段格式归一化**：取值约束收敛在 `normalize.ts` 与工具 schema 中 —— 出生年月统一 `YYYY-MM`、枚举白名单校验、数组防御性读取，保证 AI 输出永远能落进表单。

* **受控表单 + store 直连**：编辑组件直连 Zustand 单一数据源，selector 返回稳定引用，规避无限重渲染。

* **导入兜底链路**：PDF 先抽文本，抽不到转图片走视觉模型；图片先压缩再转 Base64，保证任意模型可解析。

* **数据迁移**：store 持久化带版本号迁移，历史结构升级与损坏数据修复在 rehydrate 时自动完成。

## 常见问题 FAQ

**Q：安装依赖报 peer 冲突？**

使用 `npm install --legacy-peer-deps`。

**Q：AI 对话没反应？**

先到设置页（`/#/ai`）配置 Provider 与 API Key 并「测试连接」。所有 AI 导入 / 润色 / 对话都依赖模型配置。

**Q：模板切换后内容丢了？**

不会。模板只影响布局与标题样式，数据存储在简历 JSON 里。若模板序号失效（模板列表变化），自动回退到默认模板，内容仍在。

**Q：数据存在哪里？会丢吗？**

存在浏览器 localStorage。清除浏览器数据会丢失，建议开启「本地文件夹备份」或定期导出 JSON。

**Q：为什么我的 PDF 导出和预览不一样？**

导出使用预览区按 A4 分页渲染，样式与预览一致；若发现偏差，请先刷新页面再导出。

**Q：.doc 文件能导入吗？**

不支持 `.doc` 旧格式，请用 Word 另存为 `.docx` 后导入。

## 开发扩展指南

**新增一个模板**：



1. `src/config/templates.ts` 的 `TEMPLATES` 数组追加配置（id /name/titleVariant /spacing/basic.layout）。

2. 如需新的标题样式，在 `src/components/templates/shared/sections.tsx` 的 `SectionTitleVariant` 增加变体并实现分支。

3. 模板缩略图自动复用真实渲染，无需单独维护。

**新增一个编辑板块**：



1. `src/config/modules.ts` 注册板块元信息。

2. 在 `src/components/editor/` 下新增编辑面板组件，直连 `useResumeStore`。

3. 在模板渲染侧 `sections.tsx` 新增对应 Section 组件。

**新增一个 AI 工具**：在 `src/lib/agent/langchain/tools/` 新增工具（用 Zod 定义 schema），注册进 `agent.ts` 的工具列表即可。

**修改分页规则**：分页逻辑集中在 `src/components/preview/pagination.ts`（收集 → 测量 → 截断 → 克隆），`src/index.css` 里 `.resume-rich` 与 `.rich-editor` 是预览 / 编辑两套样式，修改时注意同步。
